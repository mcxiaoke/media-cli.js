# NVIDIA GeForce 10/20/30/40/50 系 编解码 NO（不支持）分析报告

> 数据来源：`nvidia-matrix-all.csv`（NVIDIA 官方 Video Encode/Decode Support Matrix，GeForce 消费级表）
> 统计口径：每张卡按 BOARD 名称归入 10/20/30/40/50 系并去重；**无硬件的卡（Total NVENC/NVDEC = 0，如 GT 1030 无编码器）不计入 NO 分母**。
> 单元格含义 = **不支持(NO)的卡数 / 该系总卡数**。

## ⚠️ 重要口径提醒

- **RTX 2050** 名义上属「20系」，但硅片是 **Ampere**（NVENC 7th gen / NVDEC 5th gen），编解码能力与 30 系一致（如 AV1 解码 YES、HEVC 4:4:4 解码 YES）。因此下方「20系」里的 AV1 解码、HEVC 4:4:4 出现「部分支持」是 RTX 2050 拉高的；**真正的 Turing（GTX 16 / RTX 2060–2080 TU10x）在这些项上全部不支持**。
- Turing 内部有 **6th gen（GTX 16 / MX）** 与 **7th gen（RTX 20）** 两代 NVENC，**HEVC B 帧仅 7th gen 支持**。

## 三、逐系结论（仅列「不支持」项）

- **50 系 (Blackwell)**：编码、解码 **全部格式支持**，无任何 NO。当前最完整。
- **40 系 (Ada Lovelace)**：编码器仅缺 **H.264 4:2:2** 与 **HEVC 4:2:2**（两代均为全不支持）；解码器缺 **H.264 高位深/4:2:2** 与 **HEVC 4:2:2**。AV1 编解码、HEVC 4:4:4 解码均支持。
- **30 系 (Ampere)**：编码器缺 **H.264 4:2:2**、**HEVC 4:2:2**、**AV1 编码**；解码器缺 **H.264 高位深/4:2:2** 与 **HEVC 4:2:2**（HEVC 4:4:4 解码、AV1 解码均支持）。
- **20 系 (Turing，含 RTX 2050)**：编码器缺 **H.264 4:2:2**、**HEVC 4:2:2**、**AV1 编码**；**HEVC B 帧**仅 7th gen（RTX 20）支持，GTX 16 / MX 不支持（故 4/18）。解码器缺 **H.264 高位深/4:2:2**、**HEVC 4:2:2**、**HEVC 4:4:4**、**AV1**（基本都不支持，RTX 2050 例外支持 AV1 与 4:4:4）；VP8/VP9 基本支持。
- **10 系 (Pascal)**：缺口最大。编码器缺 **H.264 4:2:2**、**HEVC 4:2:2**、**HEVC B 帧**、**AV1 编码**；解码器缺 **H.264 高位深/4:2:2**、**HEVC 4:2:2**、**HEVC 4:4:4**、**AV1**，**VP9 10/12bit** 与 **VP8** 也部分不支持（仅 2–3 张支持）。

## 四、跨系规律

- **4:2:2 色度采样**是 NVENC 传统短板：10/20/30/40 系的 H.264 4:2:2 与 HEVC 4:2:2 编码 **全系不支持**，到 50 系 (Blackwell) 才补齐。
- **AV1 编码**从 40 系 (Ada) 才开始支持，30 系及更早均无。
- **AV1 解码**从 30 系 (Ampere) 才开始支持，20 系及更早基本无（Turing 无 AV1 硬解）。
- **HEVC 4:4:4 解码**从 30 系开始支持，20/10 系不支持。
- **HEVC B 帧编码**从 30 系 (Ampere) 开始全系支持；20 系仅 RTX 20 (7th gen) 支持。
