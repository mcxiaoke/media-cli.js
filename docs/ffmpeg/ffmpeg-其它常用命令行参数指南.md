# FFmpeg 其它常用命令行参数指南

> 本文档依据 FFmpeg 官方《ffmpeg-cmd》与《ffmpeg-formats》文档（对应 FFmpeg
> 9 开发版，N-126689）整理编写，覆盖 ffmpeg 命令行除了编解码器与滤镜之外的常用参数：总体结构、流选择与流说明符、通用选项、输入/输出主选项、视频/音频/字幕选项、高级选项（映射、复杂滤镜、时间戳、seek、进度统计）、封装选项（`-movflags`
> 等）以及 seek、截图、image2 序列等实战用法。
>
> 命令行写法约定：
>
> - `ffmpeg [全局选项] [输入选项] -i 输入 [输出选项] 输出 ...`
> - `-选项 值` 表示参数；`-选项:流说明符 值` 表示只作用于匹配的流（见"流说明符"一节）。
> - 输入选项放在 `-i` 之前，输出选项放在输出文件之前。

## 1. ffmpeg 命令行总体结构与组件流程

一条 ffmpeg 命令由以下顺序组成：

```
ffmpeg [全局选项] {[输入文件选项] -i 输入_url} ... {[输出文件选项] 输出_url} ...
```

处理管线为：**输入协议/文件 → demuxer（解封装）→ decoder（解码）→ filter（滤镜）→ encoder（编码）→
muxer（封装）→ 输出协议/文件**。

- **输入文件**：由 `-i` 指定，可以有多个；每个输入文件内部包含若干"流"（stream），用
  `文件序号:流序号` 标识（如 `0:0` 表示第一个输入的第 0 条流）。
- **输出文件**：一个命令可以同时生成多个输出文件；每个输出对输入流进行"映射"（默认自动，或用 `-map`
  手动指定）。
- **流**：`0:v` 表示第一个输入的所有视频流；`0:a:1` 表示第一个输入的第 2 条音频流（序号从 0 开始）。
- **转码 vs 流拷贝**：不给输出指定编码器（`-c:v`、`-c:a`）时默认转码；指定 `-c copy`
  则不做解码/编码，直接拷贝码流（速度极快、无损，但不能改变分辨率/码率等）。

## 2. 流选择（Stream selection）

默认情况下 ffmpeg 会为每个输出文件**自动选择**"最高质量"的流：

- 视频流：分辨率最高者；
- 音频流：声道数最多者；
- 字幕流：第一条字幕；
- data / attachment 流：**不会**被自动选择，必须用 `-map` 手动指定。

一旦在输出文件上使用了 `-map` 选项，**自动选择即被禁用**，输出内容完全由 `-map` 决定。

### 2.1 流说明符（Stream specifier）

流说明符用于只对匹配的流生效，写在选项名后、用冒号分隔：`-c:v`、`-b:a`、`-map 0:a:1` 等。

| 说明符           | 匹配含义                                           |
| ---------------- | -------------------------------------------------- |
| `v`              | 所有视频流；`V` 仅匹配无附件图片的视频流           |
| `a`              | 所有音频流                                         |
| `s`              | 所有字幕流                                         |
| `d`              | 所有数据流                                         |
| `t`              | 所有附件流                                         |
| `0`、`1`、`2`... | 匹配该序号的流（多输入时写作 `0:1`）               |
| `p:节目号`       | 匹配指定节目中的流                                 |
| `m:标签键[值]`   | 按元数据标签匹配，如 `0:m:language:eng` 匹配英语流 |
| `#流id`          | 按流 id 匹配                                       |
| `u`              | 可用的（可用性标志为 usable）流                    |
| `i`              | 匹配所有流时用于区分输入                           |

示例：

```
# 只编码第一个输入的视频流
ffmpeg -i in.mp4 -c:v libx264 -sn -an out.mp4
# 按语言选音频
ffmpeg -i in.mkv -map 0:m:language:eng out.mkv
```

## 4. 主要选项（Main options）

### 4.1 输入/输出文件与格式

| 选项                | 作用位置  | 说明                                                       |
| ------------------- | --------- | ---------------------------------------------------------- |
| `-f 格式`           | 输入/输出 | 强制指定输入或输出的封装格式；输出格式也可由扩展名自动推断 |
| `-i url`            | 输入      | 指定输入文件/设备/流（可多个）                             |
| `-y`                | 全局      | 覆盖输出文件而不询问                                       |
| `-n`                | 全局      | 不覆盖已有输出文件，直接退出（与 `-y` 互斥）               |
| `-stream_loop 次数` | 输入      | 循环读取输入流，`-1` 表示无限循环（如循环测试图）          |
| `-recast_media`     | 全局      | 强制按媒体类型重新匹配输入流类型（罕见）                   |

### 4.2 转码控制

| 选项                                                    | 作用位置      | 说明                                                                                                                                                                      |
| ------------------------------------------------------- | ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `-c[:流] 编码器` / `-codec[:流] 编码器`                 | 输入/输出     | 指定编解码器。输出时 `-c:v libx264`、`-c:a aac`；`-c copy` 拷贝全部流；`-c:v copy` 只拷贝视频。输入时用于强制解码器                                                       |
| `-t 时长`                                               | 输入/输出     | 输入时：限制从输入读取的时长；输出时：写到该时长即停止。时长可用 `HH:MM:SS.mmm` 或秒数                                                                                    |
| `-to 位置`                                              | 输入/输出     | 读到/写到该时间位置停止。**与 `-t` 互斥，`-t` 优先**                                                                                                                      |
| `-fs 字节数`                                            | 输出          | 输出文件大小上限（到达后不再写入，实际略大）                                                                                                                              |
| `-ss 位置`                                              | 输入/输出     | seek 定位。输入时（`-i` 前）：跳转到最近的可 seek 位置（transcode 时默认精确 seek，会解码丢弃之间的帧；`-c copy` 时不精确）；输出时（输出文件前）：解码并丢弃直到该时间戳 |
| `-sseof 位置`                                           | 输入          | 相对文件末尾 seek：`-sseof -10` 表示结尾前 10 秒；`0` 表示 EOF                                                                                                            |
| `-itsoffset 偏移`                                       | 输入          | 给输入时间戳加偏移（正数=延迟），重同步音视频用                                                                                                                           |
| `-itsscale 比例`                                        | 输入·按流     | 缩放输入时间戳（浮点数）                                                                                                                                                  |
| `-isync 输入序号`                                       | 输入          | 以某输入为同步基准，对齐两个输入的开始时间戳                                                                                                                              |
| `-timestamp 日期`                                       | 输出          | 设置容器录制时间戳                                                                                                                                                        |
| `-metadata[:说明符] 键=值`                              | 输出·按元数据 | 设置输出元数据；空值删除；如 `-metadata title="标题"`、`-metadata:s:a:0 language=eng`                                                                                     |
| `-keep_metadata[:说明符] 键`                            | 输出·按元数据 | 转码时保留某些会被丢弃的元数据键（如 `iTunSMPB`、`encoded_by`）                                                                                                           |
| `-disposition[:流] 标志`                                | 输出·按流     | 设置流 disposition，如 `-disposition:a:1 default`；以 `+`/`-` 前缀增删，`0` 清除全部                                                                                      |
| `-program [title=..:][program_num=..:]st=流[:st=流...]` | 输出          | 在输出中创建节目（program）                                                                                                                                               |
| `-stream_group 映射`                                    | 输出          | 在输出中创建流组（stream group，如 IAMF）                                                                                                                                 |
| `-target 类型`                                          | 输出          | 按目标标准快速设置参数，如 `-target pal-vcd`、`-target ntsc-dvd`                                                                                                          |

### 4.3 覆盖与默认值要点

- 输出编码器未指定时，ffmpeg 按输出封装格式挑选默认编码器（如 mp4 默认 `h264/aac`）；
- `-b:v`、`-b:a`、`-q:v` 等是编解码器章节的通用选项，此处仅说明 `-bsf`、`-tag` 等流级选项见后文。

## 5. 视频选项（Video options）

| 选项                               | 作用位置  | 说明                                                                                                                                                                     |
| ---------------------------------- | --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `-frames:v 数量` / `-vframes 数量` | 输出      | 只输出前 N 帧视频（截图/采样常用）；`-frames:a` 同理                                                                                                                     |
| `-r[:流] fps`                      | 输入/输出 | 帧率。输入时：忽略时间戳按固定帧率生成时间戳（raw 输入建议用 `-framerate`）；输出时：**复制/丢弃帧**以得到恒定帧率                                                       |
| `-fpsmax[:流] fps`                 | 输出      | 输出帧率上限（自动侦测帧率过高时钳制）；不能与 `-r` 同用；stream copy 时忽略                                                                                             |
| `-s[:流] 宽x高`                    | 输入/输出 | 帧尺寸。输出时等价于在滤镜图末尾追加 `scale` 滤镜；输入时用于 raw/抓取设备                                                                                               |
| `-aspect[:流] 宽高比`              | 输出      | 显示宽高比（`16:9`、`4:3`、`1.7777` 等）；仅 `-c:v copy` 时写容器级信息                                                                                                  |
| `-stereo3d[:流] 布局`              | 输出      | 设置 3D 布局元数据（不改像素；改像素用 `-vf stereo3d`）                                                                                                                  |
| `-vn`                              | 输入/输出 | 输入时禁止所有视频流被过滤/映射；输出时禁止录视频                                                                                                                        |
| `-vcodec 编码器`                   | 输出      | 等价 `-c:v`                                                                                                                                                              |
| `-passlogfile[:流] 前缀`           | 输出      | 两遍编码 log 文件前缀                                                                                                                                                    |
| `-pass[:流] N`                     | 输出      | 第 N 遍编码（`-pass 1`、`-pass 2`）                                                                                                                                      |
| `-vf 滤镜图` / `-filter:v 滤镜图`  | 输出      | 对该流应用简单滤镜图                                                                                                                                                     |
| `-pix_fmt[:流] 格式`               | 输入/输出 | 像素格式；`+格式` 表示若不支持则报错；单个 `+` 表示沿用输入格式且禁止自动转换                                                                                            |
| `-sws_flags 标志`                  | 输入/输出 | 自动插入 scale 滤镜的缩放算法（如 `bicubic`、`lanczos`）                                                                                                                 |
| `-rc_override[:流] 覆盖`           | 输出      | 指定帧区间码控覆盖（`起始帧,结束帧,量化器/质量因子`，用 `/` 分隔多段）                                                                                                   |
| `-vstats`                          | 输出      | 输出视频编码统计到 `vstats_HHMMSS.log`                                                                                                                                   |
| `-vstats_file 文件`                | 输出      | 指定统计文件                                                                                                                                                             |
| `-force_key_frames 时间...`        | 输出      | 强制关键帧：时间列表 `0:05:00,chapters-0.1`；`expr:表达式`（如 `expr:gte(t,n_forced*5)` 每 5 秒一个关键帧）；`source`（源关键帧）；`scd_metadata`（按 scdet 滤镜元数据） |
| `-autorotate` / `-noautorotate`    | 输出      | 按元数据自动旋转（默认开）                                                                                                                                               |
| `-autoscale` / `-noautoscale`      | 输出      | 自动按首帧分辨率缩放（默认开，慎关）                                                                                                                                     |
| `-tag[:流] 四字符码`               | 输出      | 强制视频 tag/fourcc（音频 `-atag`、字幕 `-stag`）                                                                                                                        |
| `-bits_per_raw_sample[:流] 值`     | 输出      | 原始样本位深（如 10bit raw 输出）                                                                                                                                        |
| `-frames:d 数量`                   | 输出      | 只输出前 N 帧数据流（`-dframes` 旧别名）；视频/音频分别为 `-frames:v`/`-frames:a`                                                                                        |

### 5.1 硬件加速（解码与设备初始化）

| 选项                                            | 作用位置 | 说明                                                                                                                                     |
| ----------------------------------------------- | -------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `-hwaccel[:流] 方式`                            | 输入     | 硬件解码：`none`(默认)、`auto`、`vdpau`、`dxva2`、`d3d11va`、`vaapi`、`qsv`、`videotoolbox`。多数加速仅利于播放，现代 CPU 纯软解可能更快 |
| `-hwaccel_output_format[:流] 格式`              | 输入     | 硬解后帧的存放格式：`auto`(默认，帧回内存)、`cuda`/`d3d11`/`qsv` 等（留在 GPU 内，必须配硬件滤镜如 scale_cuda 才能继续处理）             |
| `-hwaccel_device[:流] 设备`                     | 输入     | 指定硬件设备（如 `-hwaccel_device 0`）                                                                                                   |
| `-hwaccels`                                     | 全局     | 列出可用硬件加速方式                                                                                                                     |
| `-init_hw_device 类型[:名称][:设备[,键=值...]]` | 全局     | 初始化硬件设备，如 `-init_hw_device cuda:0`；用 `-init_hw_device list` 列出本机构建支持的设备类型                                        |

**关键机制说明（与官方文档一致的要点）**：

- `-hwaccel` 是**输入（解码）侧**选项；NVENC/QSV 等**编码**硬件不需要它，直接 `-c:v h264_nvenc`
  即可。
- 官方文档明确提示：**大部分 hwaccel 方法仅用于播放或断点抓帧，对转码没有帮助**（除非配合硬件滤镜做全 GPU 流水线）。qsv 是官方文档点名"可用来加速转码"的例外。
- `-hwaccel_output_format auto`（默认）会让硬解帧回到内存，后续可以自由接任何软件滤镜；换成
  `cuda`/`qsv`/`d3d11`
  则帧留在 GPU，此时**只能用对应的硬件滤镜**（scale_cuda/scale_qsv/hwupload 等），混用软件滤镜会直接报错（实测：qsv 模式下加 scale 报
  `Failed to configure output pad on FilterGraph`）。
- `-init_hw_device` 用于显式准备设备（多卡选择、VAAPI 设备路径等），转码链路中常用：

```
# 本机 FFmpeg 9.0.1 支持的设备类型（实测输出）
ffmpeg -init_hw_device list

# CUDA：初始化第 2 块卡用于解码+编码
ffmpeg -init_hw_device cuda=dev:1

# 显式初始化并选用（等价于 -hwaccel cuda，多了设备命名）
ffmpeg -init_hw_device cuda=enc:0 -hwaccel cuda -i in.mp4 \
  -vf "scale_cuda=1280:720" -c:v h264_nvenc out.mp4

# QSV：用显式设备做全链路（解码+编码均走 GPU）
ffmpeg -init_hw_device qsv=hw:qsv -hwaccel qsv -i in.mp4 \
  -vf "scale_qsv=1280:720" -c:v h264_qsv out.mp4
```

编码侧硬件（nvenc/qsv/vaapi/amf）的私有参数详见《ffmpeg-编解码器参数指南》。

## 7. 字幕选项（Subtitle options）

### 8.3 时间戳与同步

| 选项                         | 说明                                                                                                                         |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `-copyts`                    | 不处理输入时间戳，保留原值（不归零）；常与 `-start_at_zero` 搭配                                                             |
| `-start_at_zero`             | 与 `-copyts` 同时使用时，把输入时间戳平移到从 0 开始                                                                         |
| `-copytb 模式`               | stream copy 时如何设置编码器时间基：`-1`(自动, 默认)、`0`...                                                                 |
| `-enc_time_base[:流] 时间基` | 编码器时间基：`0`(按媒体类型，视频 1/帧率、音频 1/采样率, 默认)、`demux`(沿用解封装器)、`filter`(沿用滤镜图)、正数(直接指定) |
| `-fps_mode[:流] 模式`        | 视频同步/帧率模式：`passthrough`、`cfr`(复制/丢帧到恒定帧率)、`vfr`(按时间戳或丢弃重帧)、`auto`(默认，视封装器而定)          |
| `-frame_drop_threshold 阈值` | 视频帧落后多少帧被丢弃（默认 -1.1；1.0=一帧）                                                                                |

**`-fps_mode` 四种模式详解（官方 ffmpeg 文档原文语义）**：

| 模式          | 行为                                                                   | 典型用途                 |
| ------------- | ---------------------------------------------------------------------- | ------------------------ |
| `passthrough` | 完全保留源帧率/时间戳（源多大就多大），不做任何同步                    | 无损复制、逐帧工作流     |
| `cfr`         | 恒定帧率：按 `-r` 指定的帧率**复制或丢弃帧**，输出严格等间隔           | 平台标准帧率（30/60fps） |
| `vfr`         | 可变帧率：按时间戳输出已匹配帧，仅在需要时丢弃**重复帧**（不复制新帧） | 录屏、动画（帧间隔不均） |
| `auto`        | 默认，视输出封装器/具体场景自动选择 cf 或 vfr                          | 一般转码                 |

**`-r` 的使用要点（输入侧与输出侧语义完全不同）**：

- **输入侧 `-r`**：忽略源时间戳，按固定帧率给输入"生成"时间戳（raw 裸流建议用 `-framerate`
  更准确）。
- **输出侧 `-r`**：控制输出帧率，行为由 `-fps_mode` 决定：`-fps_mode cfr -r 30`
  = 复制/丢弃凑 30fps； `-fps_mode vfr -r 30` = 只丢弃不补齐。
- `-r` 与 `-fps_mode` 都可用 `[:流]` 指定流；`-r` 作用于视频流，"音频帧率"用采样率表示，无对应概念。

**帧率转换实测示例（本机 30fps 源）**：

```
# 恒定 15fps（实测输出 duration 不变、fps=15，帧被丢弃一半）
ffmpeg -i in.mp4 -fps_mode cfr -r 15 out15.mp4

# 恒定 60fps（实测输出 fps=60，每帧复制一次，文件变大）
ffmpeg -i in.mp4 -fps_mode cfr -r 60 out60.mp4

# 可变帧率（不补帧，保留源时间戳，适合动画/录屏）——实测输出 fps 仍接近源值
ffmpeg -i in.mp4 -fps_mode vfr out_vfr.mp4

# 图片序列导出固定帧率截图（第 1 秒内容每 0.5 秒一帧）
ffmpeg -i in.mp4 -fps_mode cfr -r 2 -f image2 shot-%03d.jpg

# 帧率上限：源 60fps 只保留 30fps 以下，超出帧丢弃（与 -r 互斥，不可同用）
ffmpeg -i in.mp4 -fpsmax 30 out.mp4
```

> 与 `fps` 滤镜对比：`-r` 是"输出端"同步手段，在滤镜图之后生效；`fps`
> 滤镜在滤镜图内（`-vf fps=30`）先于编码器生效，两者效果等价但风格不同，滤镜版更灵活（可指定
> `start_time`/`round`）。| `-dts_delta_threshold 秒`
> | 时间戳不连续修正阈值（MPEG-TS/HLS 等），默认 10 | | `-dts_error_threshold 秒`
> | 时间戳错误丢弃阈值，默认 30 小时（保守） |

## 10. seek、截图与 image2 实战

### 10.1 seek（`-ss`）的两种位置，结果不同

```
# 输出位置（输出文件前）：精确但慢，先解码全程再丢弃（尤其 -c copy 时不可用）
ffmpeg -i in.mp4 -ss 00:01:30 -t 10 out.mp4
# 输入位置（-i 前）：先 seek 再解码，快；转码时默认精确（-accurate_seek）
ffmpeg -ss 00:01:30 -i in.mp4 -t 10 out.mp4
# 流拷贝时输入 seek 不精确（落在关键帧上）
ffmpeg -ss 00:01:30 -i in.mp4 -c copy out.mp4
```

- `-ss 位置` + `-t 时长` 是截取片段的常用组合；
- 相对末尾：`-sseof -10` 取最后 10 秒；
- 精确 seek 语义：转码时（默认
  `-accurate_seek`）会解码并丢弃 seek 点之前的多余段；`-noaccurate_seek` 或 stream copy 时保留该段。

### 10.2 截图

```
# 单张缩略图（取第 10 秒）
ffmpeg -ss 10 -i in.mp4 -frames:v 1 out.jpg
# 多张连续截图（每秒 1 张，图像序列）
ffmpeg -i in.mp4 -fps_mode cfr -r 1 -f image2 shot-%03d.jpg
# 指定起始序号
ffmpeg -i in.mp4 -f image2 -start_number 10 shot-%03d.jpg
# 用时间戳命名（strftime）
ffmpeg -f v4l2 -r 1 -i /dev/video0 -f image2 -strftime 1 "%Y-%m-%d_%H-%M-%S.jpg"
```

image2 封装器选项：`-update 1`（固定文件名持续覆盖，如生成 GIF/缩略图用）、`-frames:v 1`、`-start_number N`（起始序号）、`-strftime 1`（文件名按时间展开）、`-frame_pts 1`（按 PTS 展开）、`-atomic_writing 1`（先写临时文件再改名）。

```
# 持续覆盖同一文件（如缩略图流）
ffmpeg -i in.mp4 -f image2 -update 1 -frames:v 1 thumb.jpg
# 从图像序列生成视频
ffmpeg -f image2 -framerate 12 -i shot-%03d.jpg -s 1280x720 -c:v libx264 out.mp4
# glob 通配输入
ffmpeg -f image2 -pattern_type glob -framerate 12 -i '*.jpg' out.mp4
```

### 10.3 GIF 与循环

```
# 视频转 GIF（-loop 0 GIF 无限循环）
ffmpeg -i in.mp4 -vf "fps=15,scale=480:-1" -loop 0 out.gif
# 无音频截段转 GIF
ffmpeg -ss 5 -t 3 -i in.mp4 -vf "fps=10,scale=320:-1:flags=lanczos" -loop 0 out.gif
```

## 11. 常用场景实战

以下示例均在 FFmpeg 9.0.1（本机实测环境）验证通过，素材为含 H.264+AAC 的 mp4。

### 11.1 视频拼接（concat）

三种拼接方式适用不同场景：

```
# 方式 A：concat demuxer + 流拷贝（最快，要求所有片段编码参数完全一致，否则会花屏/时间戳错乱）
printf "file 'a.mp4'\nfile 'b.mp4'\n" > list.txt
ffmpeg -f concat -safe 0 -i list.txt -c copy merged.mp4

# 方式 B：concat 滤镜（重编码，参数不一致也能拼，损失质量换兼容性，实测输出 6.03s）
ffmpeg -i a.mp4 -i b.mp4 -filter_complex \
  "[0:v][0:a][1:v][1:a]concat=n=2:v=1:a=1[v][a]" -map "[v]" -map "[a]" merged.mp4

# 方式 C：先统一再拼接（最稳：全部转成同分辨率/帧率/编码参数后 concat demuxer）
for f in a.mp4 b.mp4; do
  ffmpeg -i "$f" -vf "scale=1280:720,fps=30" -c:v libx264 -preset veryfast -c:a aac -ar 48000 -ac 2 "norm_$f"
done
```

> 结论：**同源同参数**用 A（秒级、无损）；**参数不一致**用 B（重编码）；**批量不规整素材**用 C 规范后再 A。

### 11.2 GIF / APNG / WebM 兼容格式转换

```
# GIF：两遍法（先 palettegen 生成调色板，再 paletteuse 上色），画质最好、体积最小（实测 2 秒 320px ~200KB）
ffmpeg -ss 0 -t 2 -i in.mp4 -vf "fps=12,scale=320:-1:flags=lanczos,palettegen" palette.png
ffmpeg -ss 0 -t 2 -i in.mp4 -i palette.png -lavfi \
  "fps=12,scale=320:-1:flags=lanczos[x];[x][1:v]paletteuse" -loop 0 out.gif

# GIF：简单法（不加调色板，体积大、有带状色块）
ffmpeg -ss 0 -t 3 -i in.mp4 -vf "fps=10,scale=320:-1:flags=lanczos" -loop 0 simple.gif

# APNG：单文件无限循环动图（-plays 0 无限循环 + -update 1 单文件，实测通过）
ffmpeg -ss 0 -t 2 -i in.mp4 -vf "fps=10,scale=320:-1" -plays 0 -update 1 out.png

# WebM（VP9 + Opus）：有损，兼容性好的网页视频格式
ffmpeg -ss 0 -t 2 -i in.mp4 -c:v libvpx-vp9 -b:v 0 -crf 32 -c:a libopus -b:a 96k out.webm

# WebM（VP9 无损）：质量优先
ffmpeg -i in.mp4 -c:v libvpx-vp9 -lossless 1 -c:a libopus out_lossless.webm
```

> GIF 调色板只有 256 色，**渐变/照片场景务必用两遍法**；APNG 支持真彩色+alpha，体积通常比 GIF 小。需要动图更小用
> `-vf "fps=8,scale=240:-1"` 降帧降分辨率。

### 11.3 多路输出（tee muxer）——单次编码写多个文件/流

tee 的关键价值：**只编码一次**（多份输出文件时省 CPU），与"多个输出文件"（各编码一次）不同。

**使用要点（官方文档）**：所有输出流必须显式 `-map`（tee 不自动选流）；不同容器需要的封装参数在 `[]`
内按 slave 单独指定；`: `为选项分隔符，值含冒号需转义。

```
# 同时输出 mp4 + mpegts（实测通过，一次编码两份）
ffmpeg -i in.mp4 -map 0:v -map 0:a \
  -c:v libx264 -preset veryfast -c:a aac \
  -f tee "[f=mp4]out.mp4|[f=mpegts]out.ts"

# 音视频分流：视频存 mp4、音频单独存 m4a（select 用流类型，实测通过）
ffmpeg -i in.mp4 -map 0:v -map 0:a -c:v copy -c:a aac \
  -f tee "[select=v]video.mp4|[select=a]audio.m4a"

# mp4 用 faststart、TS 加 dump_extra（官方示例写法；注意需要 -flags +global_header 时全局加）
ffmpeg -i in.mp4 -map 0 -flags +global_header -c:v libx264 -c:a aac \
  -f tee "[bsfs/v=dump_extra=freq=keyframe]out.ts|[movflags=+faststart]out.mp4"

# mkv slave 必须加 -flags +global_header（否则报 Invalid data，实测验证）
ffmpeg -i in.mp4 -map 0:v -map 0:a -c:v libx264 -c:a aac -flags +global_header \
  -f tee "out.mp4|[f=matroska]out.mkv"

# 单 slave 失败不影响其他（onfail=ignore，实测通过）
ffmpeg -i in.mp4 -map 0:v -map 0:a -c:v libx264 -c:a aac \
  -f tee "[onfail=ignore]out.mp4|[f=mpegts]udp://10.0.1.255:1234/"
```

> 注意：tee 的 `[]`
> 里只能放**封装/muxer 级**选项（f/bsfs/select/onfail/movflags 等），不能放编码器私有参数（如
> `b:v=2000k` 会报 "No option found"）。不同编码参数的多路输出请改用多个输出文件。

### 11.4 HLS 切片与 HTTP 直播推流

```
# HLS 切片：每 2 秒一片、不限制列表长度、边缘删除旧片（实测 6 秒素材出 3 个 ts）
ffmpeg -i in.mp4 -c:v libx264 -g 30 -sc_threshold 0 -c:a aac -b:a 96k \
  -f hls -hls_time 2 -hls_list_size 0 \
  -hls_segment_filename "seg_%03d.ts" -hls_flags delete_segments out.m3u8

# 直播推流（RTMP）：-re 按实时速率读源；-tune zerolatency 降延迟；GOP 必须固定（-g）不能有 B 帧开环
ffmpeg -re -i in.mp4 -c:v libx264 -preset veryfast -tune zerolatency \
  -b:v 2000k -maxrate 2000k -bufsize 4000k -g 30 -c:a aac -b:a 128k \
  -f flv "rtmp://your-server/live/streamkey"

# UDP 推流（低成本局域网直播）
ffmpeg -re -i in.mp4 -c:v libx264 -preset veryfast -tune zerolatency -g 30 \
  -c:a aac -f mpegts "udp://192.168.1.100:1234"
```

> 直播要点：`-re`（实时读源）+ 固定 GOP（`-g 30` 且不建议大 B 帧链，`-tune zerolatency`
> 会关闭部分缓冲）+ 恒定码率（`-b:v`/`-maxrate`/`-bufsize` 相等）。RTMP 推流地址格式
> `rtmp://主机/live/密钥`，服务端可用 nginx-rtmp / SRS / OBS 兼容端。

### 11.5 硬件 vs 软件转码对比

| 维度   | 软件（libx264）                 | 硬件（NVENC 全链路）                                                                      |
| ------ | ------------------------------- | ----------------------------------------------------------------------------------------- |
| 命令   | `-c:v libx264 -preset veryfast` | `-hwaccel cuda -hwaccel_output_format cuda -vf scale_cuda=... -c:v h264_nvenc -preset p5` |
| 压缩率 | 同码率画质更好，可控制性最强    | 同码率画质略差（但速度/功耗占优）                                                         |
| 速度   | 慢（CPU 密集）                  | 快数倍（GPU 并行）                                                                        |
| 适用   | 最终成片、归档、质量敏感        | 批量转码、直播编码、高分辨率实时处理                                                      |

```
# 软件转 1280x720（实测 3 秒片段 0.29s）
ffmpeg -i in.mp4 -ss 0 -t 3 -vf "scale=1280:720" -c:v libx264 -preset veryfast -b:v 2000k -c:a aac -f null -

# 硬件 NVENC 全链路（实测 3 秒片段 0.47s，短片时初始化开销掩盖优势；长任务/4K 优势明显）
ffmpeg -hwaccel cuda -hwaccel_output_format cuda -i in.mp4 -ss 0 -t 3 \
  -vf "scale_cuda=1280:720" -c:v h264_nvenc -preset p5 -b:v 2000k -c:a aac -f null -
```

> 短片段/低负载时硬件优势不明显（初始化开销占比大），**长任务、4K/高分辨率、大批量**才是硬件加速的主战场。本机为 gyan 版 FFmpeg
> 9.0.1 + NVIDIA GPU，其他平台 QSV/VAAPI/AMF 命令结构相同（编码器名不同）。

## 12. 综合应用实例

```
# 1) 纯转封装（不重编码，秒级完成）
ffmpeg -i in.mkv -c copy out.mp4

# 2) 全转换：H.264 + AAC，2 遍编码（先 1 后 2）
ffmpeg -y -i in.mp4 -c:v libx264 -preset slow -b:v 2000k -pass 1 -an -f mp4 /dev/null
ffmpeg -y -i in.mp4 -c:v libx264 -preset slow -b:v 2000k -pass 2 -c:a aac -b:a 128k out.mp4

# 3) 只取视频，换容器 + 重新封装
ffmpeg -i in.mp4 -map 0:v -c copy video_only.mkv

# 4) 自动选流 + 去字幕：拷贝视频、AAC 转码音频
ffmpeg -i in.mkv -map 0:v -map 0:a -c:v copy -c:a aac -sn out.mp4

# 5) 裁剪 10 秒片段 + 缩放 + 加水印
ffmpeg -i in.mp4 -vf "scale=1280:720,drawtext=fontfile='C\:/Windows/Fonts/arial.ttf':text='demo'" \
       -ss 30 -t 10 out.mp4

# 6) 自定义映射：拷贝视频，选特定音频，忽略第二条音频
ffmpeg -i in.mkv -map 0:v -map 0:a:0 -map -0:a:1 -c copy out.mkv

# 7) 多输入混流：视频 + 音频 + 硬字幕
ffmpeg -i video.mp4 -i audio.m4a -i sub.srt \
       -map 0:v -map 1:a -map 2:s -c:v copy -c:a aac -c:s mov_text out.mp4

# 8) 复杂滤镜：画中画 + 双路输出
ffmpeg -i main.mp4 -i pip.mp4 -filter_complex \
       '[1:v]scale=320:180,setpts=PTS-3[T];[0:v][T]overlay=W-w-10:H-h-10[out]' \
       -map '[out]' -map 0:a out.mp4

# 9) CBR 输出
ffmpeg -i in.avi -b:v 4000k -minrate 4000k -maxrate 4000k -bufsize 1835k -c:v mpeg2video out.m2v

# 10) 脚本友好：隐藏 banner、错误级日志、进度到管道
ffmpeg -hide_banner -loglevel error -progress pipe:1 -i in.mp4 -c copy out.mp4

# 11) 提取音频并转码
ffmpeg -i in.mp4 -vn -c:a libmp3lame -b:a 128k out.mp3

# 12) 合并两个视频（concat demuxer，需同编码/同参数）
ffmpeg -f concat -safe 0 -i list.txt -c copy merged.mp4

# 13) 全流拷贝但排除数据流（mkv 验证通过；注意 mp4/mov 封装器会按 timecode 元数据自动重建 tmcd 轨道）
ffmpeg -i in.mov -map 0 -map -0:d -c copy out.mkv
```

## 13. 常见问题速查

| 问题                               | 解法                                               |
| ---------------------------------- | -------------------------------------------------- |
| 输出文件已存在要覆盖               | `-y`                                               |
| 不想覆盖已存在文件                 | `-n`                                               |
| 转封装后网页播放秒开（MP4）        | `-movflags +faststart`                             |
| MP4 转 TS 流媒体                   | `-bsf:v h264_mp4toannexb`                          |
| TS 转 MP4 播放无声                 | `-bsf:a aac_adtstoasc`（多用于 `-c copy`）         |
| 输出异常卡在"加字幕导致时长不准"   | 用 `-c:s copy` 或烧录 `-vf subtitles=`             |
| 多流时间戳跨度大报 muxing queue 错 | `-max_muxing_queue_size 1024`                      |
| 直播推流必须实时                   | `-re`                                              |
| 脚本输出噪音大                     | `-hide_banner -loglevel error`                     |
| 需要看真实编码信息                 | `-vstats`、`-progress pipe:1`、`-loglevel verbose` |
| 截取精确秒段但太快/太慢            | `-ss` 放在 `-i` 之前（输入 seek）                  |
