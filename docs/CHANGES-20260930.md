- **信号处理**（`ffmpeg_run.js`）：删除 `if (!process.versions?.electron)` 豁免分支，
  SIGINT/SIGTERM 清理钩子无条件注册（此前分支仅为避免 GUI 主进程被 `process.exit(130)` 杀掉）。
